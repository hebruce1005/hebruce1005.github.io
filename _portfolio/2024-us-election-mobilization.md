该研究在北京外国语大学国际关系学院美国政治研究中心“历史与当下的美国”工作坊（第一期）中开展。

- 使用 Python 调用 API 并编写爬虫，采集 FEC、American Presidency Project、Meta Ad Library 等多源数据。
- 清洗、匹配并结构化整合竞选资金、集会和政治广告资料。
- 对竞选支出说明、集会演讲与政治广告文本进行规则编码和 NLP 分析，比较两党的选举动员路径。
